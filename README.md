## ✨ 企划简介

**「大肥鱼」** 是一个面向熟人社群持续迭代的原创虚拟角色陪伴与创意绘画互动企划。
她是一只总觉得肚子饿、喜欢白米饭与海鲜盖饭的蓝发鲸鱼女仆，日常驻扎在社群与专属私聊小灶中，陪大家自然接梗聊天、制作双人头像互动表情，以及将日常照片重绘为多风格插画与连载小剧场。

> **关于代码与隐私说明**：本仓库为「大肥鱼」原创角色设定、功能文档与版本更新展示站（Showcase），不包含服务端私有配置与社群聊天数据。

## 🎨 核心互动玩法

| 模块 | 玩法说明 |
| :--- | :--- |
| 💬 **活人感社群陪伴** | 结合长期熟人印象与好感度成长（路人 → 眼熟 → 熟人 → 老友 → 挚友），像真实群友一样自然接话、读懂长图与分享卡片，绝不生硬复读。 |
| 🖌️ **趣味画板与连续改图** | 支持参考图写真二创、多轮细节连续精修、群成员 QQ 头像主题画像，以及多格连载小剧场续画。 |
| 🤝 **双人头像表情工坊** | 支持摸头、贴贴、干杯等多种群友与大肥鱼的双人头像趣味互动表情生成。 |
| 🔒 **一对一专属私聊小灶** | 面向投喂伙伴开放独立好友私聊空间：单向继承群内熟人好感与称呼默契，同时**私聊照片与成图 100% 物理隔离不回流群聊**。 |
